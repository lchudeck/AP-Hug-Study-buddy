# PR 3 — AP-style practice expansion

This PR moves the Study Buddy beyond CED coverage toward exam-style application.

## Exam Lab
- 7 stimulus MCQ sets, one per unit
- 21 stimulus MCQs total
- 7 mini-FRQs, one per unit
- 21 FRQ parts total

## AP Simulator
- Original schematic transit/access map
- Original population pyramid stimulus
- Original multiple-nuclei urban model stimulus
- Original sector-change development graph
- 12 visual-stimulus MCQs
- 7 mixed-unit synthesis questions
- Timed mixed MCQ simulation using visual and cross-unit items
- 7-part mixed-unit synthesis FRQ with a scoring guide

## Design goals
1. Require students to read evidence before answering.
2. Practice scale, spatial relationships, data interpretation, models, and cause/effect.
3. Connect units rather than treating each unit as isolated vocabulary.
4. Give immediate explanations after practice, but hide feedback during the timed simulation.
5. Use original questions and original schematic visuals rather than copying College Board items.

## Remaining future work
- Continue increasing the size of the stimulus bank.
- Add more authentic map types (choropleth, dot density, isoline/cartogram-style practice).
- Add more graphs and data tables using real-world public datasets when appropriate.
- Add stronger performance analytics by AP skill and CED topic.
- Build longer simulations as the question bank grows enough to avoid excessive repetition.
